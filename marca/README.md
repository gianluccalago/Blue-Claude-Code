# Marca Blue Senior Living — exportações

Gerados a partir de `public/logo.svg` (arte vetorial original, azul `#1b3a5c`).

| Arquivo | Quando usar |
|---|---|
| `blue-logo-completa-1200x1200.jpg` | Padrão. Marca completa: emblema + BLUE / SENIOR LIVING. |
| `blue-logo-simbolo-1200x1200.jpg` | Quando o cadastro pede só o ícone (avatar, favicon, selo). |

## Especificação atendida (verificada arquivo a arquivo)

- Formato **JPG** (não PNG, não PDF)
- **1200 x 1200 px** — quadrado, acima do mínimo de 945 x 945
- **300 dpi** gravados no segmento JFIF (unidade = polegada)
- **~0,1 MB** — muito abaixo do limite de 2 MB
- **Fundo branco** sólido (255,255,255), sem transparência
- **Sem TM ou ®** — a arte é vetor de traçado puro, sem elementos de texto

## Como refazer

Renderizado em 2400 px no Chromium e reduzido para 1200 px com LANCZOS
(bordas limpas), depois salvo em JPEG qualidade 97 sem subamostragem de
croma (4:4:4), preservando os traços finos do emblema.
